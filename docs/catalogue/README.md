## Как добавить

Из корня репозитория, при запущенном Docker и после установки frontend-зависимостей:

```sh
./dev start
# В другом терминале:
node scripts/import-hotel-catalogue.mjs
```

Скрипт работает только с локальным origin 127.0.0.1:3000 и credentials окружения hotel-local-app-v1. Использует настоящий ADMIN session/CSRF API; .env и legacy-базы не читает. Создаёт каждый отель скрытым, добавляет три варианта номера и затем публикует. Существующие объекты не переписывает. Повторный запуск пропускает уже опубликованные карточки; неопределённые ошибки POST не повторяет автоматически. Журнал в ignored .local/hotel-catalogue-import.json помогает закончить собственный незавершённый черновик, если его никто не редактировал. Отели с совпадающим slug, не принадлежащие этому импорту, остаются без изменений; при несовпадении ожидаемого результата проверка остановится.

Добавление выполняется по запросу, а не при каждом старте приложения. Оно сохраняется в PostgreSQL между перезапусками. Данные источников находятся в hotels.json и входят в Git как воспроизводимый набор; секреты и идентификаторы локальной базы — только в .local/.
